# Mery Ter-Avetisyan — Portfolio

A personal portfolio featuring photography, writing, entrepreneurship, and a career in customer experience and marketing.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Edit

The website is a responsive static page. Edit `index.html` to update its content and styles. The portrait lives in `assets/portrait.jpg`. Google Fonts supplies the typefaces; system fonts are used when offline.

Photography and writing collections are placeholders awaiting selected work. The organic juice business links to https://organicjuice-yum.com/.
